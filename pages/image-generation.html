Image Generation

프롬프트만으로 업무용 이미지 만들기

첨부 이미지 없이도 보고서 커버, 발표용 개념도, 사내 캠페인 배너, 교육 자료용 그림을 만들 수 있습니다. 핵심은 목적, 독자, 화면 비율, 포함할 텍스트, 금지 요소를 명확히 쓰는 것입니다.

프롬프트 템플릿 전체 기능 보기
어디에 쓰나 작성법 수정 방식 템플릿
첨부 불가 전제

기존 이미지를 업로드해 수정하는 흐름은 사용하지 않습니다. 대신 텍스트 설명만으로 새 이미지를 만들고, 결과를 보며 수정 지시를 반복합니다.

발표 자료

슬라이드 첫 장, 섹션 구분 이미지, 개념 설명용 배경을 만듭니다.

업무 안내

사내 공지, 교육 콘텐츠, 정책 안내에 들어갈 단순하고 명확한 시각 자료를 만듭니다.

아이디어 탐색

제품 컨셉, 캠페인 무드, 프로세스 은유를 빠르게 시각화합니다.

작성법

이미지는 상세할수록 수정 비용이 줄어든다

항목 넣을 내용 예시
목적 이미지가 쓰일 문서와 독자를 밝힙니다. 신입 교육용 슬라이드에 넣을 업무 흐름 그림
구성 주요 오브젝트, 배치, 여백, 텍스트 위치를 적습니다. 왼쪽에는 사용자, 오른쪽에는 4개 기능 카드
스타일 현실 사진, 플랫 일러스트, UI 캡처풍, 아이소메트릭 등 스타일을 지정합니다. 화이트 배경, 얇은 선, 사내 가이드 문서 느낌
금지 요소 브랜드 로고, 실제 인물, 과도한 장식, 읽기 어려운 작은 글자를 제외합니다. 실제 고객명과 회사 로고는 넣지 말 것

수정 방식

전체 재생성보다 수정 지시를 작게 나눈다

1

초안 생성

비율, 목적, 톤, 핵심 구성만 정해서 첫 이미지를 만듭니다.

2

문제 지정

텍스트가 작다, 요소가 많다, 톤이 어둡다처럼 문제를 분리해 말합니다.

3

사용처 확인

슬라이드, 문서, 메신저 카드 등 실제 사용 크기에서 읽히는지 확인합니다.
